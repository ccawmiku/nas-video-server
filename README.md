# NAS Video Server

轻量、浏览器优先的 NAS 视频库，面向局域网和 Tailscale。它不刮削元数据，不维护多用户，按媒体库扫描视频文件，并在浏览器不兼容时按需使用 FFmpeg 转码。

## 当前能力

- 每个媒体库可以映射多个目录，每个媒体库显示扁平视频列表
- 标题优先读取容器 `title` 元数据，没有时使用文件名
- 按文件名、文件创建时间、文件修改时间、时长、大小排序
- 搜索、收藏夹、继续观看、播放进度、随机连续播放
- 外挂和内嵌字幕、音轨选择、低清预览缩略图
- 原画优先，自动转码；VAAPI 优先，失败回退 CPU
- 手动扫描和按媒体库设置定时扫描
- 删除操作移动到各映射目录顶层的 `废弃` 文件夹
- 密码 + 全局 TOTP，单实例永久会话
- 备份、日志、健康状态和会话撤销接口

## Compose

复制 `.env.example` 作为配置参考，修改 `compose.yaml` 中的媒体映射。媒体映射必须可写，因为“删除”会将文件移动到映射目录下的 `废弃` 文件夹。首次访问 `http://NAS地址:8096`，设置密码并绑定 TOTP。

`/dev/dri` 映射要求 NAS 主机提供可用的 VAAPI render device。容器最多同时运行两个转码任务，可用环境变量调整。

## 开发

```powershell
go test ./...
cd web
npm ci
npm run build
```

本地开发时可运行 Go 服务和 Vite 开发服务器；项目的 Docker 构建与容器测试仅在 GitHub Actions 执行。
